# DeskMind brand · [中文](BRAND.zh-CN.md)

**得心，应手。**

Supporting lines: 看得清，想明白，稳稳做。/ See. Think. Act. / 让决定，稳稳落下。

| | |
|---|---|
| Name | DeskMind; Chinese name 得心 (from 得心应手) |
| Mark | An open frame (your desk) and one orange point (a decision placed carefully) |
| Wordmark | Manrope, with Desk at weight 450 and Mind at weight 560; the dot of the i is the orange point. Manrope and Noto Sans SC are SIL OFL fonts; the assets here use outlined glyphs and bundle no font files |
| Mascot | Xiaofang (小方), the frame come to life |

## Using the brand

**You may use the name, logo and Xiaofang, unmodified, to refer to DeskMind:**
- in articles, talks and videos;
- in lists of integrations;
- in community stickers.

**Please don't:**
- modify, recolor, stretch or add effects to the logo;
- fill the gap in the frame or move the point;
- use the marks for a different product, or in a way that suggests we endorse you;
- use Xiaofang in place of the logo or scale him below 64 px;
- set the Chinese wordmark 得心 smaller than 24 px tall (below that, use the mark alone).
