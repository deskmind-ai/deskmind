**Pre-release** of 0.4.0, for testing before it becomes the latest version. 0.3.1 stays the latest until then.

## Since rc.2

- **Organising a large folder no longer fails.** On a real Downloads folder, "整理目录" still stopped at once: the local model was handed every file's list of every subfolder and ran out of memory ("metal::malloc … greater than the maximum allowed buffer size"). DeskMind now shows it a bounded part at a time, so a folder of 150 files and 12 subfolders is sorted step by step (about 18 s a step on an M4 Pro).
- The local model gets up to 2 minutes for a step, instead of 1, on slower Macs.
- **Report on GitHub now includes diagnostics,** folded at the end of the issue: the error, how long each step took, the shape of a request that failed, the versions, and the Mac's model, chip and memory. It has no screen content, file names or paths, and you can read and edit it before you submit.

## Since rc.1 (in rc.2)

- **Organising a folder with subfolders no longer fails at once.** "整理目录" on a Downloads folder with subfolders ended before its first step, saying the local model "didn't answer in time". Each file's "move to" list of every subfolder made one question too large for the model, and the request was refused. Questions now stay within the model's limits, and moves into subfolders work.
- **A rename in your own folder waits for your approval,** as deleting and sending do. It cannot be undone, and an unclear instruction could otherwise rename files to something you didn't want. The sample folder is not affected.
- **An app that isn't on this Mac is named before the run starts** ("WeChat isn't installed on this Mac…"), instead of the run trying without it.
- **The file example always names a file the folder really has.** If the attached folder has no file it could name, the example isn't shown.
- **Self-test:** after a task finishes, the window comes back, and picking another task shows Start. Task names follow the app's language.
- When the local model refuses a step, DeskMind now says that, and why, instead of saying it didn't answer in time.

DeskMind for Mac 0.4.0 shows you the window a task is working in, live, while it works in the background.

## New: a live view of the task

- **See what DeskMind is doing, wherever the window is.** A small card in a corner of the screen shows the window the task is working in, live, even when that window is behind your other windows. Under the picture is the step it is taking, in words, and a dot shows where each step acted. In the title bar, 小方 (DeskMind’s little frame) watches where DeskMind is working, looks up when it needs you, and smiles when it’s done.
- **It stays out of your way.** The card moves to another corner when it would cover the window being worked in, never takes the keyboard, and doesn't come to the front. Over an app that fills the screen it sits in the corner farthest from where DeskMind is clicking and lets clicks pass through; rest the pointer on it for a moment to use its buttons. Drag it to any corner and it stays there for later tasks. Double-click it to make it larger, or collapse it to a small capsule.
- **It tells you when it needs you.** When the task asks a question or wants your approval, the card says so; click it to answer in DeskMind. Stop is on the card too. When the task ends, the card says how it ended, then goes.
- **Only the task's window.** The card shows the window the task works in and nothing else. If that window is minimized or closed, the card says so; it never shows another window of the same app instead. The card is an ordinary window: your own screenshots and screen sharing show it. The models never see it, and task recordings leave it out (recording the whole screen keeps it).
- Turn it off in View › Show a Live View of the Task.

## Also new

- **Tell us when it gets it wrong.** After a task, 👎 asks what went wrong ("It guessed instead of asking", "Wrong result", "It got stuck") and opens a GitHub issue filled in with your instruction, the result and the steps in words. It includes only your instruction, how the task ended, the number and kinds of steps, and the versions, nothing read from your screen. You check it and submit it in your browser; DeskMind sends nothing itself. A failed run has "Report on GitHub" too, and Help › Report an Issue is always there.
- **You see the result.** When a task gives an answer, or your first task finishes, the DeskMind window comes back with it (without taking the keyboard). A notification also comes when the window is out of the way.
- **All three examples are visible** under the instruction box, one per line.

## Fixes

- **A question no longer catches what you type elsewhere.** If you were typing in another app when DeskMind asked a question, your keys (Return included) could go into the answer and send it. Now the window comes back without taking the keyboard while you type.
- **A task in an app that isn’t open, or whose window is closed, no longer ends at once.** DeskMind saw no window, and the task could end as done after one step, having done nothing (seen with NetEase Cloud Music). Now the app is opened, or its window brought back, before the task starts, without bringing it to the front.
- The file example names the file the sample folder actually holds, after a language switch too.
- The vision model is described as optional on the confirmation sheet, and the "Don't ask again" box no longer shows where it had no effect.
- Clearer words: "Didn't finish" in Chinese reads 没做完; the island says "Starting" instead of "Hands"; "Try examples" (the six diagnostics) is now "Self-test".
- Recorded runs no longer show the purple "being shared" mark in place of the task windows' traffic lights, and recordings no longer include the menu bar's status icons.
- The GitHub line after your first finished task now links to the DeskMind repository, waits until you have seen the result, and comes back after a 👍 until you have followed it once. Home has a GitHub link at the bottom.

## Changes

- The models are the same as in 0.3.x (DeskMind Brain G18b, routing threshold 0.96; Eyes-4B at de8e13b), so the published benchmark numbers still apply, and models already downloaded are not downloaded again.
- The app's source now lives in [deskmind-ai/deskmind](https://github.com/deskmind-ai/deskmind) (`app/`). This release was built and notarized by CI from the source commits pinned in `app/deps.lock`.

## Requirements

A Mac with Apple Silicon and macOS 15 or later. The planner models (about 5.3 GB) are downloaded on first launch, from Hugging Face or, if that is slow, from ModelScope. The optional vision model needs another 3.3 GB. The live view uses the Screen Recording permission DeskMind already has; macOS shows its screen-recording indicator in the menu bar while a task runs with the live view on.

## Known limitations

- Apps with no accessibility tree are read from the screen, and are briefly brought to the front while a step acts. The vision model as the app runs it (4-bit, up to 2 megapixels) scores 50.9 on ScreenSpot-Pro (67.7 on a GPU at full resolution), and small icons are its weak spot.
- Chrome's address bar is not recognised as the browser's own field; the guard that keeps table rows out of it works in Safari.
- Copying more than about four rows in a given order is less reliable than short tables.

**中文说明**

DeskMind for Mac 0.4.0：任务在后台运行时，可以实时看到它正在操作的窗口。

**新功能：任务实时画面**
- **无论窗口在哪，都能看到 DeskMind 在做什么。** 屏幕角落的小卡片会实时显示任务正在操作的窗口，即使这个窗口被你的其他窗口挡住也一样。画面下方用文字写出当前这一步，画面里的小圆点标出每一步落在哪里。标题栏里的小方会看着 DeskMind 正在操作的位置，需要你时抬头看你，完成时眯眼笑。
- **不挡你的事。** 如果卡片会挡住正在操作的窗口，它会自动换到另一个角落；它不抢键盘，也不会跑到最前面。应用占满屏幕时，卡片停在离 DeskMind 点击位置最远的角落，点击会穿透过去；鼠标在卡片上停一下，就能用它的按钮。把它拖到任意角落，之后的任务都会留在那里。双击可以放大，也可以收起成一个小胶囊。
- **需要你时会告诉你。** 任务提问或需要你批准时，卡片会提示；点一下卡片就能在 DeskMind 里回答。卡片上也有停止按钮。任务结束时，卡片会显示结果，然后消失。
- **只显示任务的窗口。** 卡片只显示任务正在操作的那个窗口。窗口被最小化或关闭时，卡片会说明，绝不会改为显示同一应用的其他窗口。卡片是普通窗口：你自己截图、共享屏幕时能看到它；模型看不到它，任务录像也不包含它（录制整个屏幕时会包含）。
- 可以在「显示 › 显示任务窗口的实时画面」里关闭。

**其他新功能**
- **做错时告诉我们。** 任务结束后点 👎，会问哪里不对（「它没问就猜了」「结果不对」「卡住了」），然后打开一个已填好的 GitHub issue 页面（只含你的指令、任务结果、步骤数量和类型、版本号，不含任何屏幕内容），由你在浏览器里检查后提交；DeskMind 自己不发送任何内容。运行出错时也有「在 GitHub 上反馈」，菜单「帮助 › 反馈问题」随时可用。
- **能看到结果。** 任务给出答案，或你的第一个任务完成时，DeskMind 窗口会带着结果回来（不抢键盘）；窗口被移开时也会发通知。
- **三个示例都能看到**，在输入框下方各占一行。

**修复**
- **整理带子文件夹的目录不会再一开始就失败。** 以前在有子文件夹的「下载」里说「整理目录」，第一步之前就结束，还提示本地模型「没及时回答」：其实是一道题太大，被模型拒绝了。现在题目不会超出模型的限制；模型真的处理不了某一步时，会如实说明原因。
- **在你自己的文件夹里改名，会先征得你同意**，和删除、发送一样（示例文件夹不受影响）。指令里提到的应用没安装时，开始前就会告诉你。文件示例只写文件夹里真实存在的文件。自检里一个任务跑完后窗口会回来，选别的任务时按钮显示「开始」，任务名跟随 App 语言。
- **提问不会再吃掉你在别处打的字。** 以前 DeskMind 提问时如果你正在别的应用里打字，按键（包括回车）可能落进答案并直接发送。现在你打字时窗口回来但不抢键盘。
- **应用没打开、或窗口被关掉时，任务不会再一步就「完成」。** 以前 DeskMind 看不到窗口，可能走一步就判定完成，实际什么都没做（网易云音乐上出现过）。现在开始前会先打开应用或找回它的窗口，且不会把它切到前台。
- 切换语言后，文件示例也会写示例文件夹里真实存在的文件名。
- 确认页把视觉模型写明为可选；不起作用的「不再询问」勾选框不再出现。
- 用词更清楚：中文「Didn't finish」改为「没做完」；顶部状态不再显示「Hands」而是「启动中」；「试试示例」（6 个自检任务）改名为「自检」。
- 录制的任务里，窗口左上角不再出现紫色的「正在共享」标记，录像里也不再出现菜单栏的状态图标。
- 第一次有任务完成后出现的 GitHub 那一行，现在链接到 DeskMind 仓库，要等你看到结果才出现；点 👍 后也会出现，直到你点过一次。首页底部加了 GitHub 链接。

**其他**
- 模型与 0.3.x 相同（DeskMind Brain G18b，路由门槛 0.96；Eyes-4B de8e13b），已公布的评测成绩依然适用，已下载的模型不会重新下载。
- App 的源码现在位于 [deskmind-ai/deskmind](https://github.com/deskmind-ai/deskmind) 的 `app/` 目录。本版本由 CI 按 `app/deps.lock` 固定的源码提交构建并公证。

**运行要求**：Apple Silicon 芯片的 Mac，macOS 15 或更高版本。首次启动会下载约 5.3 GB 的规划模型（Hugging Face 慢时自动改用 ModelScope）；可选的视觉模型另需 3.3 GB。实时画面使用 DeskMind 已有的「屏幕录制」权限；开启实时画面运行任务时，菜单栏会显示系统的屏幕录制指示。
