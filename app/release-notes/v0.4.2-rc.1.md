**Pre-release** of 0.4.2, for testing before it becomes the latest version. 0.4.1 stays the latest until then.

## Since 0.4.1

- **Moving files works when the Finder window is in icon view.** Before, a task like "make a folder called Receipts and move receipts.csv into it" created the folder and finished with the file still where it was, whenever Finder showed the folder as icons (#67). In icon view, Finder gives each item's name in a different form than in list view, and DeskMind only read the list-view form, so it never offered the move. It now reads both. List view works as before.

Nothing else has changed since 0.4.1.

0.4.2 的**预发布版**，转为正式版之前供测试。在此之前，正式版仍是 0.4.1。

**相比 0.4.1**
- **Finder 窗口是图标视图时，也能移动文件了。** 以前，只要 Finder 用图标显示文件夹，「新建一个『报销』文件夹，把 报销单.csv 移进去」这类任务会建好文件夹就结束，文件还留在原处（#67）。图标视图下 Finder 给出文件名的方式和列表视图不同，DeskMind 只认列表视图的那种，所以从来不会提供「移动」。现在两种都认。列表视图下的行为不变。

除此之外与 0.4.1 相同。
