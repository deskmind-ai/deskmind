DeskMind for Mac 0.3.1 fixes problems found in external reviews of 0.3.0. Update if you have tried the examples with unsaved TextEdit documents open.

## Fixes

- **Try examples no longer closes your TextEdit documents.** In 0.3.0, the example "Type exact Chinese text and save" closed every open TextEdit document without saving before it started, so unsaved work was lost. Now only the example's own sandbox files are closed.
- **An approval covers one step.** Approving one "Send" covered every later "Send" in the same task, even in another app. Now each send, delete, pay, publish or share asks again; the confirmation dialog it opens right after counts as the same decision.
- **The local model servers answer only to DeskMind.** The planner and vision servers on 127.0.0.1 now require a random token made on this Mac, so another program can neither use them nor pass for them. A server left over from 0.3.0 is replaced automatically.
- **Clear all deletes run data.** Clear all in Recent now also deletes the runs' step screenshots and records, and your 👍/👎, from this Mac. Recordings in Movies › DeskMind stay. The README lists what is kept where, and for how long.
- **Vision clicks near the screen's edge.** The vision model's point at the very top-left of the screen could be read as the bottom-right corner. It is now read on the model's own 0–1000 scale, and an answer outside the screen is rejected.
- Two AppleScript strings are now escaped like the others, so a folder name with a quote or a backslash cannot break them.

## Changes

- The models are the same as in 0.3.0 (DeskMind Brain G18b, routing threshold 0.96; Eyes-4B at de8e13b), so the published benchmark numbers still apply. A machine that already downloaded them for 0.3.0 does not download them again.

- In the Chinese interface, the product is called DeskMind.
- After your first task that finishes, one line offers the GitHub repository. It shows once, can be closed, and sends nothing.
- This release was built and notarized by CI, from the source commits pinned in `prototype/deps.lock`.

## Requirements

A Mac with Apple Silicon and macOS 15 or later. The planner models (about 5.3 GB) are downloaded on first launch, from Hugging Face or, if that is slow, from ModelScope. The optional vision model needs another 3.3 GB.

## Known limitations

- Apps with no accessibility tree are read from the screen, and are briefly brought to the front while a step acts. The vision model as the app runs it (4-bit, up to 2 megapixels) scores 50.9 on ScreenSpot-Pro (67.7 on a GPU at full resolution), and small icons are its weak spot.
- Chrome's address bar is not recognised as the browser's own field; the guard that keeps table rows out of it works in Safari.
- Copying more than about four rows in a given order is less reliable than short tables.

**中文说明**

DeskMind for Mac 0.3.1 修复了外部评审在 0.3.0 中发现的问题。如果你在打开着未保存的 TextEdit 文档时用过「试试示例」，建议更新。

- **「试试示例」不会再关掉你的 TextEdit 文档。** 0.3.0 里，「中文精确写入并保存」这个示例开始前，会把所有打开的 TextEdit 文档不保存直接关掉，未保存的内容会丢失。现在只关闭示例自己的沙盒文件。
- **一次批准只对一步有效。** 以前批准过一次「发送」，同一个任务里之后所有的「发送」都不再询问，换了应用也一样。现在每次发送、删除、付款、发布、分享都会重新询问；紧跟着弹出的确认框算同一次决定。
- **本地模型服务只响应 DeskMind。** 127.0.0.1 上的规划服务和视觉服务，现在要求带上本机生成的随机令牌，其他程序既用不了，也冒充不了。0.3.0 留下的旧服务会被自动替换。
- **「全部清除」会删除运行数据。** 在「最近的任务」里点「全部清除」，现在会同时从这台 Mac 上删除这些任务的步骤截图、运行记录，以及你的 👍/👎；录像保留在「影片 › DeskMind」中。README 里写明了每类数据存在哪里、保留多久。
- **视觉模型在屏幕边缘的定位。** 视觉模型给出的屏幕左上角附近的点，可能被误读成右下角。现在按模型自己的 0–1000 尺度解读，超出屏幕的结果会被拒绝。
- 两处 AppleScript 字符串补上了转义，文件夹名里有引号或反斜杠也不会出错。
- 模型与 0.3.0 相同（DeskMind Brain G18b，路由门槛 0.96；Eyes-4B de8e13b），已公布的评测成绩依然适用；装过 0.3.0 的机器不会重新下载模型。
- 中文界面里的产品名改为 DeskMind；第一次有任务完成后，会出现一行可关闭的 GitHub 链接，只出现一次，不发送任何数据。
- 本版本由 CI 按 `prototype/deps.lock` 固定的源码提交构建并公证。

**运行要求**：Apple Silicon 芯片的 Mac，macOS 15 或更高版本。首次启动会下载约 5.3 GB 的规划模型（Hugging Face 慢时自动改用 ModelScope）；可选的视觉模型另需 3.3 GB。
