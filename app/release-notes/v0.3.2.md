DeskMind for Mac 0.3.2 fixes a task ending at once when its app isn’t open yet.

## Fixes

- **A task in an app that isn’t open, or whose window is closed, no longer ends at once.** DeskMind saw no window, and the task could end as done after one step, having done nothing (seen with the NetEase Cloud Music example right after installing). Now the app is opened, or its window brought back, before the task starts, without bringing it to the front. Finder, TextEdit, Preview and the iWork apps are opened by the task itself, as before.
- Recorded runs no longer show the purple “being shared” mark in place of the task windows’ traffic lights, and recordings no longer include the menu bar’s status icons.
- The one-time line after your first finished task links to the DeskMind repository on GitHub.

## Changes

- The models are the same as in 0.3.1 (DeskMind Brain G18b, routing threshold 0.96; Eyes-4B at de8e13b), so the published benchmark numbers still apply, and models already downloaded are not downloaded again.
- The app’s source now lives in [deskmind-ai/deskmind](https://github.com/deskmind-ai/deskmind) (`app/`). This release was built and notarized by CI from the source commits pinned in `app/deps.lock`.

## Requirements

A Mac with Apple Silicon and macOS 15 or later. The planner models (about 5.3 GB) are downloaded on first launch, from Hugging Face or, if that is slow, from ModelScope. The optional vision model needs another 3.3 GB.

**中文说明**

DeskMind for Mac 0.3.2 修复了应用还没打开时任务一开始就结束的问题。

- **应用没打开、或窗口被关掉时，任务不会再一步就「完成」。** 以前 DeskMind 看不到窗口，可能走一步就判定完成，实际什么都没做（刚装好就试网易云音乐示例时出现过）。现在开始前会先打开应用或找回它的窗口，且不会把它切到前台。访达、文本编辑、预览和 iWork 仍由任务自己打开。
- 录制的任务里，窗口左上角不再出现紫色的「正在共享」标记，录像里也不再出现菜单栏的状态图标。
- 第一次有任务完成后出现的那一行，现在链接到 GitHub 上的 DeskMind 仓库。
- 模型与 0.3.1 相同，已公布的评测成绩依然适用，已下载的模型不会重新下载。
- App 的源码现在位于 [deskmind-ai/deskmind](https://github.com/deskmind-ai/deskmind) 的 `app/` 目录；本版本由 CI 按 `app/deps.lock` 固定的源码提交构建并公证。

**运行要求**：Apple Silicon 芯片的 Mac，macOS 15 或更高版本。首次启动会下载约 5.3 GB 的规划模型；可选的视觉模型另需 3.3 GB。
