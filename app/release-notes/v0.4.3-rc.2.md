**Pre-release** of 0.4.3, for testing before it becomes the latest version. 0.4.2 stays the latest until then.

## Since 0.4.2

- **Searching the web from Safari works (#73).** Before, "open Safari and search for the weather in Singapore" could type into a search box on the open page and report the task done, and "search in the smart search field" was refused. Now:
  - DeskMind offers the address bar as one action, "search in the address bar". A model checks that searching there is what you asked for before anything is typed.
  - The search goes into the Safari window DeskMind looked at, and is stopped if that window moved or changed in the meantime.
  - Other text still never goes into the address bar. For example, copying a table from a page into a file does not type the table there.
  - At the end, a model reads the page that is open. If the result you asked for is not there, the task is not reported as done.
- **An app that isn't in front is still seen.** Before, if Safari was open but another app was in front, DeskMind could see no Safari window at all and report the task done without doing anything. Now it reads the app's window even when the app is in the background. Minimised windows are never used.
- **"Done" needs something to show for it.** When DeskMind can see no window at all, a task is reported done only if a model confirms the result needs no window, for example a file saved and then closed, and something was actually done. The one exception is a goal that was already true at the start. Otherwise the task stops as not confirmed.
- **A locked screen stops the task.** Before, a task started while the Mac was locked could report done without doing anything. Now it stops and says the screen is locked.

## Since rc.1

The last three items above are new. Testing rc.1 showed that a task could be reported done without anything happening when Safari was in the background or the screen was locked.

**中文说明**

0.4.3 的**预发布版**，转为正式版之前供测试。在此之前，正式版仍是 0.4.2。

**相比 0.4.2**
- **在 Safari 里搜索网页能用了（#73）。** 以前，「打开 Safari，搜索新加坡的天气」可能会把字打进当前网页自带的搜索框，然后报告完成；「在智能搜索栏里搜索」则会被拦下。现在：
  - 地址栏作为一个动作出现：「在地址栏搜索」。打字之前，先由模型确认在这里搜索正是你要的。
  - 搜索只打进 DeskMind 看过的那个 Safari 窗口；如果这期间窗口挪动或换了，就停下不打。
  - 其他内容仍然不会打进地址栏。比如把网页上的表格抄进文件，不会把表格内容打到地址栏里。
  - 结束前，由模型读一遍当前打开的网页；你要的结果不在上面，就不报告完成。
- **应用不在最前面也能看到。** 以前，Safari 开着但前面是别的应用时，DeskMind 可能一个 Safari 窗口都看不到，什么都没做就报告完成。现在应用在后台也能读到它的窗口；最小化的窗口一律不用。
- **说「完成」要有依据。** 一个窗口都看不到时，只有模型确认这个结果本来就不需要窗口（比如文件存好后关掉了），而且确实做过事，才报告完成；一开始就已经是你要的样子的除外。否则以「无法确认」停下。
- **锁屏时会停下。** 以前在锁屏状态下开始的任务，可能什么都没做就报告完成。现在会停下，并说明屏幕已锁定。

**相比 rc.1**

上面后三条是新加的。测试 rc.1 时发现，Safari 在后台或屏幕锁定时，任务可能什么都没发生就报告完成。
