DeskMind for Mac 0.4.3 makes web searches in Safari work, and stops DeskMind from reporting a task done when nothing happened.

## Fixes

- **Searching the web from Safari works (#73).** "Open Safari and search for the weather in Singapore" could type into a search box on the open page and report the task done, and "search in the smart search field" was refused.
  - DeskMind now offers the address bar as one action, "search in the address bar". A model checks that searching there is what you asked for before anything is typed.
  - Other text still never goes into the address bar.
  - Checked on two Macs with the installed app, with Safari in the background. The three phrasings from #73 ("search for…", "in the smart search field…", "with Baidu…") all reached the search results.
- **DeskMind works in its own browser window and leaves yours alone.** For a task in Safari, DeskMind opens a new window of its own in the background, titled "DeskMind 的窗口" at first, and works only there.
  - Windows you already had are never read, brought back from the Dock, or navigated. The same goes for windows you open while the task runs.
  - The window stays open when the task ends, so you can see the result.
  - The first time, macOS asks whether **DeskMind Hands** may control Safari. If you don't allow it, the task stops and says where to turn it on: System Settings › Privacy & Security › Automation › DeskMind Hands.
- **"Done" needs something to show for it.**
  - In Safari, a model checks the page in DeskMind's window before a task is reported done. If the page can't be read, or the check gives no answer, the task stops as not confirmed.
  - When no window can be seen at all, a task is reported done only if both of these hold:
    - a model confirms the result needs no window, for example a file saved and then closed;
    - something was actually done.

    A goal that was already true at the start also counts as done.
- **An app that isn't in front is still seen.** If Safari was open but another app was in front, DeskMind could see no Safari window at all and report the task done without doing anything.
- **A locked screen stops the task.** A task started while the Mac was locked could report done without doing anything. Now it stops and says the screen is locked.
- **If the page you mean is in your own window, DeskMind says so.** It asks which address to open or what to search for, or it stops and says why. In this version it doesn't yet act on your answer.

It is built from the same code as pre-release [v0.4.3-rc.4](https://github.com/deskmind-ai/deskmind/releases/tag/v0.4.3-rc.4). The models are the same, and models already downloaded are not downloaded again.

## Known

- **Browser tasks work in Safari only for now.**
  - In Chrome, DeskMind can't see the page, and a search is typed but not submitted. The task ends without being reported done.
  - Firefox and Arc aren't supported yet. A task there stops rather than use your window.
- **A task can occasionally hang for several minutes** before it stops with an error, when reading a page's structure stalls.
- If DeskMind asks you a question and gets no answer, it may carry on for a step before stopping.
- In Notes, DeskMind can't yet select a note in the list, so tasks on a single note don't work there (deskmind#49).

## Requirements

A Mac with Apple Silicon and macOS 15 or later.

**中文说明**

DeskMind for Mac 0.4.3 让在 Safari 里搜索网页能用了，并且不再在什么都没发生时报告「完成」。

**修复**
- **在 Safari 里搜索网页能用了（#73）。** 以前，「打开 Safari，搜索新加坡的天气」可能会把字打进当前网页自带的搜索框，然后报告完成；「在智能搜索栏里搜索」则会被拦下。
  - 现在地址栏作为一个动作出现：「在地址栏搜索」。打字之前，先由模型确认在这里搜索正是你要的。
  - 其他内容仍然不会打进地址栏。
  - 在两台 Mac 上用装好的 App 测过，Safari 在后台时，#73 里的三种说法（「搜索……」「在智能搜索栏里搜索……」「用百度搜索……」）都打开了搜索结果。
- **DeskMind 在自己的浏览器窗口里做事，不碰你的窗口。** 在 Safari 里做任务时，DeskMind 会在后台新开一个自己的窗口（一开始显示「DeskMind 的窗口」），只在这个窗口里操作。
  - 你原来开着的窗口，以及任务进行中你自己新开的窗口，都不会被读取、从程序坞里弹出来或者被跳转。
  - 任务结束后这个窗口会留着，方便你看结果。
  - 第一次使用时，macOS 会问是否允许 **DeskMind Hands** 控制 Safari。如果不允许，任务会停下，并告诉你去哪里打开：系统设置 › 隐私与安全性 › 自动化 › DeskMind Hands。
- **说「完成」要有依据。**
  - 在 Safari 里，报告完成之前，由模型看一遍 DeskMind 窗口里的网页。读不到网页，或者判断没有给出答案，就以「无法确认」停下。
  - 一个窗口都看不到时，下面两条都满足才报告完成：
    - 模型确认这个结果本来就不需要窗口（比如文件存好后关掉了）；
    - 确实做过事。

    一开始就已经是你要的样子的，也算完成。
- **应用不在最前面也能看到。** 以前，Safari 开着但前面是别的应用时，DeskMind 可能一个 Safari 窗口都看不到，什么都没做就报告完成。
- **锁屏时会停下。** 以前在锁屏状态下开始的任务，可能什么都没做就报告完成。现在会停下，并说明屏幕已锁定。
- **你要处理的网页在你自己的窗口里时，DeskMind 会说明。** 它会问你要打开哪个网址、或者搜索什么，或者停下并说明原因。这一版还不会根据你的回答继续做。

这一版和预发布版 [v0.4.3-rc.4](https://github.com/deskmind-ai/deskmind/releases/tag/v0.4.3-rc.4) 用的是同一份代码。模型没有变化，已经下载的模型不会重复下载。

**已知问题**
- **浏览器任务目前只支持 Safari。**
  - 在 Chrome 里，DeskMind 看不到网页内容，搜索词打进去了却不会提交，任务不会报告完成。
  - 暂不支持 Firefox 和 Arc，在这两个浏览器里的任务会停下，而不是用你的窗口。
- **偶尔会卡住几分钟。** 读取网页结构卡住时，任务会过几分钟才以出错停下。
- DeskMind 问你问题、没有得到回答时，可能还会再做一步才停下。
- 在「备忘录」里，DeskMind 还不能在列表中选中某条备忘录，所以针对单条备忘录的任务暂时做不了（deskmind#49）。
